# Fake-review-detector
 Classify and predict whether a online product review is fake or genuine 
 Designed NLP project to categorize reviews as Real review or Fake review.
 ◦ Vector embedding were made using TF-IDF and CBOW.
 ◦ Dataset containing nearly 100k data points of online product reviews were trained using various machine
 learning algorithms.
 ◦ The best-performing algorithm was the support vector classifier.
